Cách dùng

  1. Bôi đen 1 từ hoặc 1 câu tiếng Anh (trên Chrome, PDF, Word…)
  2. Nhấn nhanh Ctrl Ctrl
  3. Bấm vào icon MTrans hiện cạnh chuột để xem bản dịch

Lấy API key

  1. Vào console.anthropic.com, chọn đúng tổ chức (Individual Org) có credits
  2. Mở API Keys → Create Key, copy key
  3. Dán vào tab Cài đặt → bấm Kiểm tra

Mỗi lần dịch tốn khoảng 0,0001–0,005$ tuỳ model, trừ vào credits của bạn.
