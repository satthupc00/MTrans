Meshes and weights

Before you start animating, you need to rig the character by binding mesh vertices to bones, so the skeleton can deform the image smoothly.
rig/rɪɡ/dựng xương (nhân vật)
động từ
  1. dựng khung xương (cho nhân vật để làm animation)
  2. lắp đặt, trang bị (thiết bị)
  3. gian lận, sắp đặt trước (kết quả)
danh từ
  1. bộ khung xương / bộ điều khiển của nhân vật
  2. giàn khoan
You need to rig the character before animating.
Bạn cần dựng xương cho nhân vật trước khi làm animation.
Cách hoạt động:
  • Lần đầu chỉ xin Claude 1 nghĩa ngắn, nên popup hiện rất nhanh và tốn ít credits.
  • Bấm More thì mới hỏi thêm phần chi tiết. Từ nào đã tra rồi thì app nhớ lại, lần sau hiện ngay mà không tốn thêm credits.

Cách dùng

  1. Bôi đen 1 từ hoặc 1 câu tiếng Anh (trên Chrome, PDF, Word…)
  2. Nhấn nhanh Ctrl Ctrl → bản dịch hiện ngay cạnh chuột

Lấy API key

  1. Vào console.anthropic.com, chọn tổ chức có credits (Individual Org)
  2. Mở API Keys → Create Key, copy key
  3. Dán vào tab Cài đặt → bấm Kiểm tra
