Cách dùng

  1. Bôi đen 1 từ hoặc 1 câu tiếng Anh (trên Chrome, PDF, Word…)
  2. Nhấn nhanh Ctrl Ctrl → bản dịch hiện ngay cạnh chuột
  3. Với 1 từ, bấm More để xem thêm nghĩa và câu ví dụ
  4. Bấm ra ngoài hoặc nhấn Esc để đóng

Dịch chữ trong ảnh, game, video

  1. Nhấn nhanh Shift Shift (hoặc chuột phải icon khay → Chọn vùng màn hình)
  2. Kéo chuột khoanh vùng có chữ, thả ra là dịch
  3. Chữ khó đọc? Bấm Thử với Claude trong popup

Lấy API key

  1. Vào console.anthropic.com, chọn tổ chức có credits (Individual Org)
  2. Mở API Keys → Create Key, copy key
  3. Dán vào tab Cài đặt → bấm Lưu

Chế độ Google không cần API key.

Chuột trái vào icon MTrans ở khay hệ thống để tạm tắt/bật lại. Chuột phải để mở menu.
